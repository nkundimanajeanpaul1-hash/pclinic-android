    Before this, toasts, backup warnings and the reset wizard were English-only.
    The button text shown while work runs ("Signing in...", "Saving...") is included,
    along with the clipboard/e-mail replies, the "Unknown" chart labels and the
    "Other (specify)" option.
  * Kinyarwanda now covers the lock screen, the reset wizard, backup encryption and
    the force-password dialog. THESE 102 KINYARWANDA SENTENCES ARE MY DRAFT - have a
    Kinyarwanda speaker read them before you ship to the clinic.
  * A wrong password/PIN now keeps slowing sign-in down (30s, 1m, 2m, 4m ... 30m)

    resets it. A 4-digit PIN is no longer guessable in an afternoon.

  * Test "nothing the user reads is hardcoded English" fails if anyone puts an
    English sentence back into a toast, dialog, button label or field label, or
    leaves a French/Kinyarwanda line identical to the English one.
  * Test "a wrong credential costs more time on every try" runs the lockout code
    itself: doubling, the 30-minute ceiling, surviving a restart, clearing on a good
    password, and never locking anyone out over a damaged counter.
